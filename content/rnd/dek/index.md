### The Project

**Dek** strips presentation software down to one idea: a deck is just a Markdown file. No proprietary format, no bloated editor — write slides the way you'd write notes, and Dek renders them with a considered, restrained visual language (its own typography and spacing rules are documented as a design system in the repo).

It's used to build several of the lecture decks published on this site.
