### The Project

**ND Player** is a native mobile client for [Navidrome](https://www.navidrome.org/), a self-hosted music server. Built with React Native and Expo against the Subsonic REST API, it's the highest-commit mobile project in this portfolio — iterated heavily around playback reliability, library browsing, and offline behavior.
